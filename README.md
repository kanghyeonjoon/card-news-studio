# 카드 스튜디오 — 공개 편집기
로그인 없이 원문을 카드뉴스로 구성하고 사진·문구를 편집해 PNG ZIP으로 내려받는 브라우저 앱입니다.

## 사용
1. 주제와 원문을 입력합니다.
2. 카드별 사진, 제목, 본문, 브랜드를 수정합니다.
3. PNG 전체 다운로드로 이미지, 편집용 project.json, caption.txt를 저장합니다.
4. project.json은 불러오기로 다시 편집합니다.

원고와 업로드 사진은 사용 중인 브라우저에서 처리됩니다. 자동 저장은 해당 브라우저에만 남습니다. Instagram 로그인·게시·예약 및 개인 발행 데이터는 포함하지 않습니다. AI 직접 호출 없이 프롬프트 복사와 JSON 가져오기를 지원합니다. 외부 사진은 이용자가 사용 권한을 확인해야 합니다.

## 실행/배포
이 폴더를 정적 웹 서버로 제공하세요. GitHub Pages에서 main 브랜치 루트를 배포할 수 있습니다. 서버 API나 비밀 키가 필요하지 않습니다.

포함 라이브러리: JSZip 3.10.2, html-to-image 1.11.13, Pretendard. 각 라이선스 파일을 참고하세요.
